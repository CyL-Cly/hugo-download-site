# Appteka

一款第三方安卓应用商店客户端，用于浏览、搜索并安装各类安卓应用与游戏的安装包资源。

第三方应用市场客户端提供应用与游戏的分类浏览、搜索和安装包获取功能，并可查看应用更新与版本信息。相比系统自带商店，这类市场在收录范围上更宽，常被用来寻找特定应用或自行管理安装包。适合喜欢手动安装应用、需要备份安装包的安卓用户。
