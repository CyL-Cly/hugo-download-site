# DirectX

DirectX 是 Windows 上支撑图形、声音与输入的多媒体组件集合，很多游戏和影音软件依赖它运行。

DirectX 提供游戏与多媒体程序调用显卡、声卡和输入设备的接口，缺组件时常见表现为游戏启动失败、画面异常或声音缺失。重装或补齐这套运行库，常用于系统重装后恢复游戏环境、修复旧游戏兼容问题，适合装机和经常折腾游戏环境的玩家。
