# smart dock安卓

Smart Dock 安卓版，把手机接上外接屏后切换成桌面式的操作界面。

连上显示器和键鼠，手机就能当一台轻办公用的小主机，窗口可以并排摆放。适合出差只带手机、临时要处理文档的人，实际顺不顺畅要看机型对外接视频输出的支持。
