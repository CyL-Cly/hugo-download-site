# TranslucentTB

TranslucentTB，把 Windows 任务栏改成透明或毛玻璃效果的小工具。

装完任务栏可以和壁纸融在一起，支持全透明、亚克力几种模式，还能跟随窗口状态自动切换。适合喜欢清爽桌面的 Windows 10 与 11 用户，3.3 MB 的体积常驻内存占用也很低。
