# Putty

PuTTY 是一款轻量的远程终端连接工具，支持 SSH、Telnet 和串口登录，常用于管理服务器、网络设备与开发板。

PuTTY 是一款开源免费的终端连接工具，支持 SSH、Telnet、串口和文件传输等常用协议，界面简洁、体积小巧，解压后即可运行。它常被用来远程登录 Linux 服务器、交换机路由器等网络设备，以及调试开发板和嵌入式系统，适合运维人员、网络工程师和需要远程操作设备的技术爱好者使用。
