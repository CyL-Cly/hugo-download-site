# Zig编程

Zig 是一门面向系统编程的现代编译型语言，语法简洁、无隐藏内存分配，常用于替代 C 开发底层程序与工具链。

Zig 是一门强调可读性与可控性的系统级编程语言，提供编译期代码执行、手动内存管理和跨平台交叉编译能力，不引入隐式控制流和垃圾回收。它可直接调用 C 库，也能作为 C 的编译器使用，适合编写操作系统、嵌入式程序、命令行工具和高性能服务。上手需要一定底层基础，适合有 C 或 C++ 经验的开发者。
