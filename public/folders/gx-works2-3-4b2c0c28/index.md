# GX Works2、3

GX Works2 与 GX Works3 是三菱可编程控制器的编程软件，用于编写程序、配置参数并下载到设备调试。

这两款软件用于可编程逻辑控制器的工程开发，支持梯形图、结构化文本等编程方式，可完成硬件组态、参数设定、程序下载与在线监控调试。它们广泛用于产线设备维护、电气自动化项目实施和教学实训，适合电气工程师、设备维护人员与自动化专业学生。
