# Logi.Options+

罗技官方外设管理软件，用于自定义鼠标与键盘的按键、指针设置和设备配置。

Logi Options+ 是罗技为自家鼠标键盘提供的配置软件，可以修改按键功能、调节指针速度、设置滚轮与手势操作。它支持为不同应用分别保存配置方案，切换窗口时自动套用，也便于在多台电脑之间共用一套外设。适合使用罗技外设、希望把鼠标键盘调得更顺手的用户。
