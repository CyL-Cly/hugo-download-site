GitHub Store 面向习惯使用开源软件的用户，把散落在 GitHub 各仓库中的桌面应用集中展示，提供分类、搜索、更新提示与一键安装。它适合不想在网页和发布页之间来回翻找的人，也方便在重装系统后快速补齐常用工具。
